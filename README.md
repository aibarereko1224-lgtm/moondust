# Moon Dust V2

Moon Dust is a quiet, private place for keeping film and reading notes.

This repository contains the new V2 foundation, built from scratch with React, TypeScript, Vite, Supabase, and Netlify.

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when a Supabase project is ready. The app can run without those values during this initial phase.

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` type-checks and creates a production build.
- `npm run preview` previews the production build locally.
- `npm run lint` runs ESLint.
